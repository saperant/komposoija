# Glossary

| Term | Definition | Chapter |
|---|---|---|
| **Accidental** | ♯, ♭ or ♮ altering a note by a semitone | 01 |
| **Anticipation / push** | A note or chord arriving before the beat it belongs to, usually tied over | 03, 09 |
| **Appoggiatura** | Accented non-chord tone approached by leap, resolving by step | 09 |
| **Arpeggio** | Chord notes played one after another | 13 |
| **Backbeat** | Accent on beats 2 and 4 | 03, 11 |
| **Bar / measure** | A group of beats defined by the time signature | 03 |
| **Borrowed chord** | Chord taken from the parallel key/mode (modal mixture) | 08 |
| **BPM** | Beats per minute (tempo) | 03 |
| **Break** | Interruption of the groove: solo break, drum break, stop-time | 03 |
| **Breakdown** | Stripped-back section; in metal, a heavy half-time chug section | 03, 10 |
| **Bridge (middle eight)** | Contrasting section, usually before the final chorus | 10 |
| **Build** | Section/passage of increasing intensity before a chorus or drop | 13 |
| **Cadence** | Chord motion that ends a phrase (authentic, plagal, half, deceptive) | 08 |
| **Chord tone** | A note belonging to the current chord | 09 |
| **Chromatic** | Using notes outside the key / moving by semitones | 04 |
| **Circle of fifths** | Keys arranged in perfect fifths; shows key relationships | 05 |
| **Comping** | Rhythmic chordal accompaniment | 13 |
| **Consonance / dissonance** | Stable vs. tense sounding intervals/chords | 02 |
| **Contour** | Shape of a melody (up/down) | 09 |
| **Diatonic** | Belonging to the key's scale | 07 |
| **Dominant** | ^5 / the V chord; the function of tension pointing to the tonic | 07 |
| **Downbeat** | Beat 1 of a bar | 03 |
| **Drop** | The climactic instrumental hook section in EDM-pop | 10, 14 |
| **Dynamics** | Loudness and intensity, and their changes | 13 |
| **Enharmonic** | Same pitch, different name (C♯ = D♭) | 01 |
| **Extension** | 9th, 11th, 13th added to a chord | 07 |
| **Fill** | Short flourish (often drums) at the end of a phrase | 03, 11 |
| **Four-on-the-floor** | Kick drum on every quarter note | 03, 11 |
| **Ghost note** | Very soft note (usually snare) adding groove | 11 |
| **Groove** | The rhythmic feel produced by the interplay of parts | 11 |
| **Half-time** | Snare on beat 3 only, feels half as fast | 03, 11 |
| **Harmonic rhythm** | Rate of chord changes | 08 |
| **Hook** | The most memorable musical idea of a song | 09 |
| **Interval** | Distance between two pitches | 02 |
| **Inversion** | Chord with a non-root note in the bass; or an interval flipped | 02, 07 |
| **Key** | Tonal centre + scale | 05 |
| **Leading tone** | ^7 of the major scale, a semitone below the tonic | 04 |
| **Mode** | Scale formed by starting the major scale on a different degree | 06 |
| **Modulation** | Change of key | 05 |
| **Motif** | Short melodic/rhythmic idea used as building material | 09 |
| **Octave** | Interval of 12 semitones; double the frequency | 01 |
| **Parallel key** | Same tonic, different mode (C major / C minor) | 05 |
| **Pedal point** | Sustained/repeated bass note under changing harmony | 08, 12 |
| **Pentatonic** | Five-note scale (major: 1 2 3 5 6; minor: 1 ♭3 4 5 ♭7) | 04 |
| **Phrase** | Musical sentence, typically 2–4 bars | 03, 09 |
| **Pickup (anacrusis)** | Notes before the first downbeat of a phrase | 03 |
| **Pitch class** | Note name regardless of octave (0–11) | 01 |
| **Power chord** | Root + fifth (+ octave), no third | 07 |
| **Pre-chorus** | Section that builds from the verse into the chorus | 10 |
| **Relative key** | Major and minor keys sharing a key signature (C / Am) | 05 |
| **Riff** | Short repeated instrumental figure | 09 |
| **Roman numeral** | Chord label relative to the key (I, ii, V7, ♭VII) | 07 |
| **Scale degree** | Position of a note in the scale (^1–^7) | 04 |
| **Secondary dominant** | V chord of a diatonic chord other than I (V/V, V/vi) | 07 |
| **Semitone (half step)** | Smallest interval in 12-TET | 01 |
| **Sidechain** | Compression of one track triggered by another (bass ducks for kick) | 12, 14 |
| **Slash chord** | Chord over a specified bass note (C/E) | 07 |
| **Stop-time** | Band plays short hits and leaves silence between | 03 |
| **Subdominant** | ^4 / the IV chord; pre-dominant function | 07 |
| **Suspension / sus chord** | 3rd replaced by 2nd or 4th | 07, 09 |
| **Swing / shuffle** | Uneven long–short subdivision | 03 |
| **Syncopation** | Emphasis on weak beats/offbeats | 03 |
| **Tempo** | Speed of the beat | 03 |
| **Time signature** | Beats per bar / beat unit (4/4, 6/8) | 03 |
| **Tonic** | Home note / I chord | 04, 07 |
| **Triad** | Three-note chord of stacked thirds | 07 |
| **Tritone** | Interval of 6 semitones | 02 |
| **Turnaround** | Short progression that leads back to the beginning | 03, 08 |
| **Vamp** | Repeated one- or two-chord pattern | 08 |
| **Voice leading** | How individual chord voices move from chord to chord | 07 |
| **Voicing** | Arrangement of chord notes across octaves/instruments | 07 |
| **Whole step (tone)** | Two semitones | 01 |
